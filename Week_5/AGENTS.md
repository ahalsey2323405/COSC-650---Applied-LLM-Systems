# Agent context file

This week's assignment focused on how to do chunking of documents and find results. I took 8 pages of technical documents on a remote control car, having the agent answer questions finding certain information inside of those 8 documents.

## Scope
Utilizes Jupyter notebook files, python
Gemini-3.6-flash model
chunking tools like beautiful soup to get documents from html

## AI usage
I primarily used AI to modify the chunking code to account for 8 documents since it wasn't originially built for multiple separate documents. Also used it to format some results. All written analysis is my own.
