# COSC-650---Applied-LLM-Systems

## Content
This repo will contain my assignments, projects and any potential notes for the COSC 650 - Applied LLMs class at Maryville University
Each week of the course will have its own folder, with corresponding assignments and notes for each week contained within the corresponding folder.

## Documentation
Folders are named Week and then the corresponding week number, ranging from Week_1 - Week_8
Inside each folder will have an "Assignment" folder, and if I took additional notes that week it will also contain a "Notes" folder, anything that falls outside of the purview of either of those folders will be placed in an additional "Miscellaneous" folder.

# Software used
This course will contain files and content using the following languages/software:
Python 3.10, Jupyter Notebook/VS Code,
Gemini API Calls
