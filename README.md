# COSC-650---Applied-LLM-Systems

## Content
This repo will contain my assignments, projects and any potential notes for the COSC 650 - Applied LLMs class at Maryville University
Each week of the course will have its own folder, with corresponding assignments and notes for each week contained within the corresponding folder. AI documentation is supplied for each assignment in the AGENTS file accompanying the assignment.

## Documentation
Folders are named Week and then the corresponding week number, ranging from Week_1 - Week_8
Inside each folder there is an assignment that was done that week, and an AGENTS file documenting my AI usage in the file. Additionally discussion board post code is included by week (If applicable).

## Brief overview of week content
# Week1 - Token analysis, we looked at how tokens differed depending upon the language and word.
# Week2 - We looked at how sampling techniques can perform differently.
# Week3 - Focused on how different prompts effect results, showed that more specific prompts got better answers.
# Week4 - Looked at how AI can utilize tools to generate answers and streamline its workflow.
# Week5 - We used different chunking methods on a database + retrieval augmented generation to pull information out of a large database.
# Week6 - Built upon week 5 RAG techniques and used PRF and ReRanking to improve metrics.
# Week7 - tested how dynamic few shot examples can guide AI and generate better predictions.
# Week8 - Combined techniques from weeks 4, 5 and 7 to create a comprehensive database assistant.
