# Agent context file

This week's assignment looks at English vs German tokenization using the tiktoken library using the cl100k_base and o200k_base tokenizers. 
The analysis compares the token counts between two passages, one in german and one in english, looking at total words, token splits and total space occupied in a 128,000 token window.

## Scope
Utilizes Jupyter notebook files, python
Showcasing difference in token counts from languages
Utilizing the tiktoken library to get token counts
